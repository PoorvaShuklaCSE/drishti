# drishti
DRISHTI (Data-driven Road Intelligence & Safety Tracking Initiative) is an AI-powered road intelligence platform that automatically detects, verifies, and analyzes road hazards using data collected from multiple vehicles. The system combines Camera, GPS, and IMU data with AI-based hazard detection and GPS data fusion to identify unique road hazards, calculate road health and risk levels, recommend safe speeds, and visualize real-time road intelligence on an interactive web dashboard.
